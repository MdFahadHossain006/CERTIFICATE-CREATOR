## ✨ Features

- **Logo Upload** – Add your organization/event logo  
- **Signature Upload** – Insert authorized signature  
- **Border Color Picker** – Customize certificate border  
- **Certificate Color Picker** – Change background/certificate color  
- **Dynamic Name Field** – Enter participant name  
- **Description Field** – Add custom message or achievement  
- **Real-time Preview** – See changes instantly  
- **Download as PDF** – Save certificate locally  
- **Print Certificate** – Direct browser printing  
- **Contact Developer Section** – Easy support access  

## 🧰 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- html2canvas / jsPDF (for PDF generation)

## 🚀 How to Use

1. Upload logo and signature (optional)  
2. Choose border and certificate colors  
3. Enter participant name and description  
4. Click "Update Certificate" to preview  
5. Download PDF or Print
